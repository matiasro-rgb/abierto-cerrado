# abierto-cerrado
[Abierto Cerrado.zip](https://github.com/user-attachments/files/34051781/Abierto.Cerrado.zip)
Este principio dice que una clase debe estar abierta para agregar nuevas características, pero cerrada para modificar su código existente, en este ejemplo, la clase Producto tiene los datos generales de un producto, como el nombre y el precio. A partir de esta clase se crean las clases Fisico y Digital.
